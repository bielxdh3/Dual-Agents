# Support

Dual Agents is under active development. The best support path depends on the kind of problem you have.

## Bugs

Open a bug report when you can describe a reproducible problem in the repository.

Before filing:

- check that you are using a supported Python and Node.js version;
- capture the Dual Agents version or commit;
- identify the provider/backend and configured role involved;
- reproduce with the smallest safe configuration you can;
- remove secrets and private repository data from logs.

Use the bug-report issue form so the report includes the information needed for triage.

## Feature requests

Use the feature-request issue form. Explain the workflow problem first, then the proposed solution.

## Setup and usage questions

Check these documents first:

- [README.md](README.md)
- [docs/CLI.md](docs/CLI.md)
- [docs/APP-INTEGRATION.md](docs/APP-INTEGRATION.md)
- [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md)

If the existing documentation does not answer the question, open an issue with the relevant environment and command output.

## Security issues

Do not use a public support issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## What to redact

Never post:

- access tokens or API keys;
- provider authentication files;
- cookies or session material;
- private repository source code unless you intentionally want it public;
- full local paths when they reveal sensitive information;
- raw logs that contain secrets.
